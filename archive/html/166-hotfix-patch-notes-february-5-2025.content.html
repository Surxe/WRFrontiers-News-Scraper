Attention, Pilots! The following hotfix will be deployed for War Robots: Frontiers following a short period of maintenance on February 5, 2024. 

General Fixes & Improvements

  • Improved overall game client stability.
  • Robot names now properly truncate if they extend beyond UI boundaries.
  • Fixed an issue where the button for the fifth weapon slot in the ‘Apply to Other Modules’ menu may have been displayed beyond the boundaries of the UI element. The button is now properly nested inside the element.
  • Added GPU Debug Mode option to Graphics Settings.
  • Titan Matriarch Hive Weapons: Corrected ATK at max level from 12057 to 1206 (visual display error only; actual in-game damage remains unchanged).
  • Improved Workshop sound effects for a more immersive experience.
  • Optimized Lighter’s visual effects to improve frame rate when firing.
  • Various localization fixes and updates.
