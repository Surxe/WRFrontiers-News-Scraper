Attention, Pilots! The following update for War Robots: Frontiers will be deployed after a short maintenance period on August 4, 2026.
The Quantum Core mode will be temporarily disabled after the update, replaced by Infinite Fuel.

New Content

  • New Event Pass: Scorching Heat
  • New War Robot: Helios
  • New Weapon: Pyre
  • Player progression expanded
  • Bugfixes and various changes

New Event Pass: Scorching Heat (August 4 – 24)

Unlock the latest robot Helios, Aftershock and Zeus weapons, Wyrm Robot as well as various resources and new cosmetics!

New War Robot: Helios

The latest Mayflower Flanker features a brand-new wheeled chassis for enhanced speed and horizontal mobility. Helios can outmaneuver pursuers and disrupt enemy positions using ramps as springboards, though it sacrifices vertical mobility, as its jetpacks are less effective for gaining altitude. Its Flaming Rider ability drops pools of napalm behind the robot to deter chasers, while teleportation lets it outsmart enemies and escape effortlessly.

Starting August 4, Helios will be available through Daily Deals, direct offers and the new Event pass.

New Robot Weapon: Pyre

Heavy close-range flamethrower firing a high-temperature stream. Ideal for melting down damaged heavy robots or flanking snipers. Its AoE damage makes aiming easier, maintaining optimal range is key to success.

Starting August 4, Pyre will be available through Daily Deals and direct offers. It might be featured in a Battle Pass or Event Pass later.

Player Progression

Player account progression has been expanded. The maximum player level has been increased to 269.

New crafting unlocks:

  • Level 257: Iron Veil
  • Level 260: Zenit Weapon
  • Level 263: Garuda Shoulder Modules
  • Level 266: Garuda Chassis Modules
  • Level 269: Garuda Torso Modules

Various changes for Quantum Core Mode

  • Added notification for core fusion.
  • Updated the game mode button text to clearly indicate that it is clickable.
  • Statistics now show enemy cores delivered to base and friendly cores recalled to base.
  • Implemented several bot behavior improvements.
  • The Core now attaches to the robot's back with an icon displayed above it.

Bugfixes and various changes

  • Fixed various crashes and implemented game stability improvements.
  • Improved VFX for Relic Thunder.
  • Fixed a bug where the workshop would function incorrectly on some new accounts.
  • Fixed a bug where the texture on Relic Bulgasari would reset in customization.
  • Fixed a bug where beacon letters were duplicated in Quantum Core on the Mont map, resulting in two A beacons.
  • Fixed a bug where the armor on Anansi Chassis was reduced by 4 points at level 13.
  • Fixed a bug where the faction for Iris pilot did not match her talent—faction has been changed to Fortevo.
  • Fixed a bug where PS controllers did not work when connected to PC (Steam and My Games Launcher).
  • Fixed a bug where recalling the core to base on timeout couldn't be interrupted in Quantum Core.
  • Fixed a bug where the UI could disappear in the hangar after receiving a match reward.
  • Fixed a bug where the Quantum Core column would leak into other modes on the match results screen.
