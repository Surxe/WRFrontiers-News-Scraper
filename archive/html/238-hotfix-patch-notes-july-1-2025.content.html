Attention, Pilots! The following hotfix will be deployed for War Robots: Frontiers following a short period of maintenance on July 1, 2025.

New Content

New Event Map

Event Duration: July 1 - July 8

  • Added the limited-time event map to the map pool: Solidus Node: Depot
  • This map supports all gameplay modes (Spearhead, Team Deathmatch, Last Robot Standing, Warp Rush).
  • This map has the same rate of appearing as other maps.

New Titan Weapon (Jigsaw)

Event Duration: July 1 - July 8

  • Grim now supports a second weapon: Jigsaw
  • Jigsaw is now available in Slot 5 and 6 of Daily Deals with a higher drop change during the event.

Gameplay Adjustments

  • Account Progress Interface: Two new buttons added to Titan rewards showing the Titan’s Modules and Stats.
  • Crew Matchmaking: When in a two-player Crew, pressing Ready no longer initiates matchmaking if the other player leaves.
  • Workshop: Existing War Robot Modules now display before blueprint items in the Module list.

Balancing Adjustments

  • Typhon (Blackout) 
    • Projectile trajectory reworked, now significantly faster for better long-range targeting.
    • Cast time reduced from 0.7s → 0.3s.
  • Volta (Cascade):
    • Level 2 → 3: Rate of Fire +9
    • Level 6 → 7: Shield Damage +109
    • Level 10 → 11: Rate of Fire +10
  • Bot Variety: Bots now use a wider variety of Builds.

Bug Fixes

General

  • Fuel Regeneration: Fixed a bug where fuel would stop regenerating.
  • In-Match Display: Fixed a bug where “Longest player name possible” would appear when a player leaves the match.
  • Job Title: “The Phenomenon" Job for FortEvo now displays the Job name correctly
  • League Rewards: Fixed a bug where Diamond and Emerald League Rewards (Milestone 1 Sticker and Milestone 2 Decal) were displayed in the incorrect order.
  • Weekly Jobs: Spearhead mode Job goals reduced from 2000s → 500s.
  • UI Fix: Players who leave a match are no longer displayed as active squad members.

Maps & Modes

  • Last Robot Standing: Player indicators no longer disappear after respawning. The user interface now correctly displays the actual player count in battle

War Robots

  • Cyclops (Death Ray): Beam no longer remains on the field after the Cyclops is destroyed.
  • Loki (Holographic Decoy): The decoy no longer awards kills to the enemy team when destroyed.
  • Loki (Holographic Decoy): The description now specifies that all active effects, including those from gear modules, are transferred to the Decoy.
  • Loki (Holographic Decoy): Fixed a bug where the game could crash in certain situations.
  • Pursuer (Optical Camo): Fixed a bug where Pursuer would remain visible on the minimap when invisible.
  • Tyr (Repair Drone): Fixed a bug that could prevent healing from being applied.

Weapons

  • Gemini: Improved trajectory prediction when using aim assist.
