Attention, Pilots! The following hotfix will be deployed for War Robots: Frontiers following a short period of maintenance on July 22, 2025.

New Content

Solidus Node: Foundry

Event duration: July 22 - July 29

  • Added the limited-time event map to the map pool: Solidus Node: Foundry.
  • This map supports all gameplay modes (Spearhead, Team Deathmatch, Last Robot Standing, Warp Rush).
  • This map has the same rate of appearing as other maps.

Special Job Event

Event duration: July 22 - July 29

  • Complete additional Daily and Weekly Jobs to earn more Credits and Intel for the duration of the event.

More details for this event will be shared on July 22 in a separate publication.

Gameplay Adjustments

  • Added a unique camera shake effect for the “Bisector” Weapon.

Bug Fixes

  • The Ceres Core Gear “Rejuvenator” decal no longer disappears when the War Robot jumps.
  • Resolved an issue where the Ceres Core Gear “Rejuvenator” percentage stat values were rounding up.
  • Resolved an issue where Shoulder Modules would disappear on lower graphical settings after the Torso from certain War Robots became damaged.
  • Resolved an issue where the label “OWNED” was not appearing on Shop bundles that players had already purchased.
  • Resolved an issue where incorrect text appeared when the Import Robot Code in the workshop was not correct.
  • Resolved an issue on PlayStation 5 that was causing crashes.
