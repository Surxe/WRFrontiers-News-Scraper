These patch notes detail changes for the War Robots: Frontiers build available from July 7, 2023.

BUGS FIXED

  • Fixed an issue that prevented Supply Line completion notifications from appearing on the Hangar screen.
  • Fixed the BACK button in the Squad window immediately opening the main Hangar view.
  • Fixed an issue that allowed accounts with the Titans feature still locked to open Titan Constructor.
  • Fixed Vortex missiles detonating before reaching maximum range.
  • Fixed armor modules disappearing at random during the match.
  • Fixed AI bots getting stuck at certain locations on Crash Site.

OTHER IMPROVEMENTS

  • Updated Pilot character icons.
  • Added animation when unlocking a Supply Line.
