These are the patch notes for the War Robots: Frontiers build available from December 28, 2022.

QOL IMPROVEMENTS

  • Upon saving a Robot build into a loadout preset, the preset will now get the name of the Hangar slot in which the build was assembled.

  • Upon importing a loadout preset, the preset name will now be identical to the code randomly generated on the end of the player who created the preset.

BUGS FIXED

  • Fixed the issue that caused holographic replacements to render on top of other items in the Hangar.
