Attention, Pilots! The following patch will be deployed for War Robots: Frontiers following a short period of maintenance on March 24, 2026.

New Content

New War Robot: Heike

Built for aggressive frontline engagements, Heike blends durability with surprising mobility, enabling it to lead fast pushes and thrive in close-quarters combat.

Starting March 24, Heike will be available through Daily Deals and direct offers.

New Event Pass: Steel Advance

Running from March 24 to April 13, the Steel Advance Event Pass brings the Hitcher War Robot, Nucleon weapons, tactical gear, and a wide selection of cosmetics.

New Events

Salvage & Intel Discount Event (March 24–31)

Upgrading your battle builds just got even more rewarding. Intel remains a crucial resource, and now you can push your upgrades further than ever with a massive 50% discount on Salvage upgrades.

This week, the Tortuga engineers invite Pilots to take a closer look at the following builds:

  • War Robot Modules: Scorpion, Lancelot, Grim (Titan)
  • Weapons: Tusk, Punisher, Katzbalger (Grim Titan), Jigsaw (Grim Titan)
  • Gear: Repulsor, Gamma Beam, Sprint Reactor, Reflector

Gameplay Adjustments

Game Modes Selector

  • The Unranked queue has been replaced with the Solidus Node Set, which now includes the following maps:
    • Solidus Node: Depot
    • Solidus Node: Foundry
    • Solidus Node: Umbra
    • Solidus Node: Bastion
  • The Infinite Fuel game mode has been temporarily reintroduced due to community requests.

Matchmaking

  • Adjustments to AI enemies have been made in Bronze, Silver, Gold, and Platinum Leagues based on player feedback.

Localization

  • Localization has been updated. Missing translations for certain languages have been added.

Interface

  • The chassis armor calculation interface has been updated:
    • Module cards now display the armor of a single leg.
    • The assembled robot card now displays total armor, taking into account the number of legs.

Bug Fixes

  • Fixed an issue preventing some players from adding Volta to the Hangar.
  • Fixed a bug where Minefield would stop working after the death of the player who deployed it. It now continues to function as intended.
  • Fixed a bug where damage dealt to the Crusher on Fissure was incorrectly added to final statistics.
  • Fixed a bug affecting post-battle calculations when some players left the match early.
  • Fixed a bug causing decals to be placed incorrectly on certain Titans and Robots.
  • Fixed an issue where some stats were not correctly applied to Ravana following the latest balance changes.
  • Fixed a bug where lock-on target markers remained visible after a robot’s destruction.
  • Updated the description of the Tyr War Robot to correctly display repaired armor values.
  • Fixed a bug where some Gear displayed rounded stats (Tesla Coil, Short Circuit, Galvanic Screen, Ripper, Snare, Nanite Field, Ion Volley, Kinetic Barrier, Warp Armor).
  • Fixed a bug where Ragnarok (Fenrir Core Gear) did not display complete information. It now shows the percentage increase in damage dealt.
  • Fixed an issue allowing access to unintended rooftop areas on the Tortuga map.
  • Fixed a bug where Anansi and Crix modules could not be correctly installed on other War Robots.
  • Fixed a bug where Ion Disruptor blocked jump and dash abilities.
  • Fixed a bug where Volta could perform an additional jump after using Grim’s Snare.
  • Fixed a bug where some commands were not displayed correctly in the ping wheel.
  • Fixed a bug related to Minefield gear proximity detection.
  • Fixed a bug in Elimination mode where using Gear after picking up Orbital Strike could freeze the interface.
  • Applied potential fixes for stuck spots on the Catalyst map.
  • Improved map traversability in areas where robots could get stuck or clip under textures.
  • Bots now avoid tight spaces on Horizon One and no longer attempt to path through them.
  • Fixed an issue where some tutorial pop-ups could not be closed when using a gamepad.
