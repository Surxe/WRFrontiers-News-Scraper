Attention, Pilots! The following patch will be made to War Robots: Frontiers (Early Access), which will be available following a short period of maintenance on April 10, 2024. 

Squads

  • Fixed an issue that allowed friends to be invited to squads that were already full.
  • Fixed an issue where a squad invite would take up a squad slot even after the player had already joined the squad.
  • After being kicked out from a squad, the player’s squad code is now updated as intended. 
  • The indicator for ready squad members now shows the current number of squad members, not the maximum number.

Robots, Titans, Weapons & Abilities

  • Reduced prices for crafting/upgrading/selling modules of all rarities by 20%.
  • Fixed the description of the Infinite Ammo ability.
  • Fixed an issue with the description of Infinite Ammo, where the primary and secondary stats were mixed up.
  • Titan: Grim’s Ensnare ability now has a distinctive sound effect.
  • Fixed a bug with a decrease in the armor value at level 2 of the Purifier torso upgrade.
  • Firing animations for Scourge, Gozer, and Incinerator weapons were improved.
  • Fixed a bug with the drones of the Titan Matriarch Missile Defense ability not being visible to the player that activated the ability.
  • Titan abilities and parts now correctly display the associated play style description tags.

Customizations

  • Fixed a bug where decals were not shown on Purifier Robot modules.
  • Customization no longer disappears when using the Trick, Blink, Teleport, and Stealth abilities.
  • Decal placement is no longer reset when switching between parts or selecting another decal.
  • 3D icons for materials, weathering, and skins on the reward screen are now of appropriate size.

Pilots 

  • Pilot reactions audio is now enabled by default in the game settings.
  • The background camera of the Pilot’s profession screen can no longer be rotated.
  • Fixed an issue that caused audio static to play when capturing a beacon using a legendary Pilot.

Maps

  • Fixed an issue with Robots spawning in inappropriate places on the Spectrum map in Team Deathmatch mode.
  • Lava on Catalyst no longer deals infinite damage.

UI Improvements

  • Fixed an issue where the brightness of the game’s logo did not change on the brightness setting screen during the first launch of the client.
  • The Battle Pass tutorial tips now all display correctly. 
  • Offers can now be purchased using the quick purchase option.
  • Post-match statistics no longer incorrectly duplicate players' names.
  • Friends invited from other platforms now appear in the Friend List as soon as they are added.

Technical Fixes

  • Additional optimization added to improve performance on lower-end PC specifications.
